# settlement-mate

정산메이트는 공동 경비와 이미 주고받은 송금을 모아 누가 누구에게 얼마를 보내야 하는지 계산하는 Streamlit 앱입니다. 그리디로 첫 정산안을 만들고, 백트래킹과 분기 한정으로 송금 횟수를 줄입니다. 5초 안에 최소 횟수를 확정하지 못하면 그때까지 찾은 최선의 정산안을 표시합니다.

## 실행

Python 3.10 이상이 설치된 환경에서 다음 명령을 실행합니다.

```bash
git clone https://github.com/suhyeon1ee/settlement-mate.git
cd settlement-mate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

터미널에 표시된 Local URL을 브라우저에서 엽니다. 입력 내역은 현재 브라우저 세션에 보관되므로 필요한 결과는 세션을 닫기 전에 다운로드합니다.

## 시연 예시

1. **참여자** 탭에서 A, B, C를 차례로 등록합니다.
2. **지출** 탭에서 아래 두 건을 각각 입력하고 저장합니다.

   | 지출명 | 결제자 | 금액 | 부담자 | 분담 방식 |
   | --- | --- | ---: | --- | --- |
   | 식비 | A | 30,000원 | A, B, C | 균등 분담 |
   | 택시비 | B | 12,000원 | B, C | 균등 분담 |

3. **기존 송금** 탭에서 C가 A에게 이미 보낸 4,000원을 저장합니다.
4. **정산 결과** 탭에서 **정산 계산**을 누릅니다. A가 받을 금액은 16,000원이고, B와 C가 각각 보낼 금액은 4,000원과 12,000원입니다. **C → A 12,000원**, **B → A 4,000원**의 두 번으로 정산됩니다.

## 결과 다운로드

**송금 목록 CSV 다운로드**는 최종 송금 순서·송금자·수령자·금액·결과 상태를 `settlement.csv`로 저장합니다. 추가 송금이 없으면 열 제목만 저장합니다.

**개인별 잔액 CSV 다운로드**는 모든 참여자의 총결제액·총부담액·기존 송수신액·정산 직전 잔액을 `balances.csv`로 저장합니다. 양수는 받을 금액, 음수는 보낼 금액입니다.

두 파일 모두 원 단위 정수와 UTF-8 BOM 인코딩을 사용합니다. 입력을 수정해 저장하면 **정산 계산**을 다시 눌러 최신 결과를 다운로드할 수 있습니다.
